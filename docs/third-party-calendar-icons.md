# Third-party calendar icons

The calendar subscription panel uses these inline SVG provider marks:

- Google G: [gilbarbara/logos `google-icon.svg`](https://raw.githubusercontent.com/gilbarbara/logos/main/logos/google-icon.svg)
- Apple mark: [gilbarbara/logos `apple.svg`](https://raw.githubusercontent.com/gilbarbara/logos/main/logos/apple.svg)
- Outlook envelope: [vscode-icons `file_type_outlook.svg`](https://raw.githubusercontent.com/vscode-icons/vscode-icons/master/icons/file_type_outlook.svg)

The Google and Apple marks are from the [gilbarbara/logos collection](https://github.com/gilbarbara/logos), which is released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The Outlook graphic is the classic envelope icon from vscode-icons; it is not presented as the latest official Outlook app mark.
